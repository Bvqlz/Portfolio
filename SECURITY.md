# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by opening an issue on this repository or by contacting the maintainer directly through the links in the README.

When reporting, please include:
- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact, if known
- Any suggested mitigation, if you have one

You can expect an initial response within 7 days. Once the issue is confirmed, I'll work on a fix and coordinate disclosure.

Thank you for helping keep this project secure.
